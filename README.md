- `main.py` — writes the joke to `/output/entry.txt`. No network, no
  dependencies, Python 3.13 standard library only.

## The joke

> My AI pair programmer is so fast, my job is now just approving diffs I
> don't understand and hoping the tests forgive me.

120 characters. The truth every developer who works beside an agent
recognises at once from the diff in front of them: the agent writes the
code at inhuman speed, and the human's job quietly becomes nodding at
diffs they barely read — with the punchline landing on the tests, the one
thing left that can still say no.
